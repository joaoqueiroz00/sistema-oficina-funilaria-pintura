
# Sistema de Oficina de Funilaria e Pintura

Sistema de gerenciamento de oficina desenvolvido em Java como projeto acadêmico da disciplina de Programação Orientada a Objetos.

O projeto tem como objetivo aplicar conceitos de orientação a objetos no desenvolvimento de uma aplicação desktop com interface gráfica.

## Tecnologias utilizadas

- Java
- Java Swing
- Apache Maven
- NetBeans IDE
- Programação Orientada a Objetos (POO)

## Funcionalidades

O sistema possui interfaces para gerenciamento de informações relacionadas às atividades de uma oficina automotiva.

Entre os módulos desenvolvidos estão:

- Cadastro de clientes
- Cadastro de profissionais
- Cadastro de veículos (carros, motos e caminhonetes)
- Cadastro de materiais
- Cadastro de prestação de serviços
- Cadastro de ordens de serviço

## Conceitos de Programação Orientada a Objetos

O projeto foi desenvolvido para aplicar conceitos fundamentais de POO, incluindo:

- Classes e objetos
- Encapsulamento
- Herança e especialização de classes
- Organização e reutilização de código
- Separação de responsabilidades entre classes

## Como executar

1. Instale um JDK compatível com a versão configurada no projeto.
2. Abra o NetBeans IDE.
3. Selecione File > Open Project.
4. Escolha a pasta que contém o arquivo `pom.xml`.
5. Aguarde o Maven carregar as dependências.
6. Execute a classe principal do sistema pelo NetBeans.

## Armazenamento de dados

O projeto utiliza coleções Java para gerenciar os registros em memória durante a execução.

Os dados não são armazenados permanentemente em um banco de dados.

## Objetivo acadêmico

Projeto desenvolvido para consolidar conhecimentos de Programação Orientada a Objetos por meio da construção de um sistema desktop voltado ao gerenciamento de uma oficina automotiva.
